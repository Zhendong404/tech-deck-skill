# Layer 2 · Slide 级规划（页内逻辑 → 版式路由与容量预算）

完成 Deck 大纲后，逐页确定「页内逻辑、对应版式、图文面积配比与字数预算」，再进入组件装配。

## 1. 单页规划四要素

每页动笔前先锁定以下 4 项：

1. **判断句主标题（Headline）**：一句话给出本页结论（16-30 字），禁止写「XX 论文解读」类话题标签。
2. **页内逻辑类型（Page Logic）**：明确本页属于因果流、双篇对比、三篇正交还是全景/收束。
3. **图文槽位（Content & Visual Slots）**：规划每栏文字要点与对应图表/表格，确保**图文并茂、高信息密度**。
4. **底部洞察启示（So What）**：1-2 条面向自身工程/架构/编译实践的具体判断或动作。

## 2. 页内逻辑 → 版式路由表（16:9 宽屏：`13.33 × 7.50 in`）

| 页内核心逻辑 | 标准页型 | 核心坐标骨架（单位：英寸） | 适用场景 |
| --- | --- | --- | --- |
| **宏观趋势 + 要点导读** | 1. 趋势词云页 | 左图区 ~68% + 右观察区 ~30%（4-5 条编号观察） | 会议/行业年度热点演进 |
| **多层系统全景** | 2. 三层架构全景 | 3 条通栏横带（左 `1.57` 标签栏 + 右 3-4 子列），中层 `#C00000` 红框高亮，层间红箭头 | 整套报告总览、技术栈定位 |
| **章节切换 / 命题定调** | 3. 章节红带页 | 纯白底居中满宽红带 `(0, 3.16, 13.33, 1.36)`，白字 `23 pt` 标题 + `16 pt` 论点 | 章节分隔与核心论点定调 |
| **单篇旗舰（重指标+多维）** | 4. KPI + 三栏 | 顶 4 等分 KPI 卡 `(y=1.20, h=0.61)` + 下 3 等分卡 `(w=4.02, h=4.39, gap=0.14)` | 旗舰论文或系统方法论全景 |
| **单篇因果闭环** | 5. 三栏因果流 | 问题 `(x=0.50, w=3.55)` → 方案 `(x=4.30, w=4.76)` → 收益 `(x=9.31, w=3.52)`，栏间 `16 pt` 红 `→` | 单篇深度拆解（最常用） |
| **双篇对比 / 互补 / 串联** | 6. 双栏卡片 | 左右等分 `(x=0.50 / 6.77, w=6.06, h=5.14, gap=0.21)`；可选顶条 `(y=1.17, h=0.40-0.57)` | 同主题双篇对比或上下游串联 |
| **三篇并列 / 三维正交** | 7. 定义条 + 三栏 | 顶定义条 `(y=1.15, h=0.57)` + 下 3 等分卡 `(w=4.02, h=4.55)`，标号 `① ② ③` 对齐 | 3 篇论文拆解 3 个正交维度 |
| **终页趋势收束** | 8. 终页收束页 | 左 ~58%「传统共识 → 新现实」表 + 右 ~40%「共性规律盒 + 观察悬念盒」+ 底红条 `(y=6.59, h=0.50)` | 报告收尾、范式迁移与行动倡议 |

### 统一页框安全区

- **左右边距**：`0.50 in`（有效内容宽 `12.33 in`）。
- **页眉区**：`y = 0.28..1.06 in`（主标题 `y=0.28, h=0.41` + 副标题/出处 `y=0.70, h=0.26` + 水平灰线 `y=1.06, h=0.01`）。
- **主内容区**：常规 `y = 1.21..6.35 in`（高 `5.14 in`）；含顶部导语/串联条时卡片从 `y = 1.67-1.81 in` 起。
- **底部「洞察启示」条**：`(0.50, 6.49, 12.33, 0.59)`，浅灰底 `#F2F2F2` + 左侧 `0.03 in` 红色竖条 `#C00000`。
- **页码**：右下角 `(12.40, 7.15, 0.44, 0.20)`，`9 pt` `#525252`。

## 3. 高信息密度与图文并茂预算

- **图文面积比**：每张内容卡片保持 **40%-55% 图表/表格 + 45%-60% 精炼文字**。原则上每张主卡片至少配 1 张高信息量视觉元素（原文架构图、定量结果图、极简对比表或原生流程条），杜绝整栏纯文字堆砌。
- **密度与留白平衡**：
  - 高密度页正文 `8.2-9.0 pt`，图注 `7.5-8.0 pt`，一页完整承载 1 篇深度拆解或 2-3 篇对比，不做成大字号空洞海报。
  - 同页多栏的图文重心和底部位置尽量对齐；若某栏图上方出现超过 `0.4 in` 的空洞留白，优先补全方案的 `①②③` 机制细节或适度放大有效图表，不要靠拉大字号凑篇幅。
- **超限处理顺序**：文字放不下时，按以下顺序收敛：删背景废话 → 压缩修饰语为短引导词 → 合并同类数字 → 仍超限则拆页，不把字号压到 `7.5 pt` 以下。
