# Layer 3 · Component 级装配（Design Tokens 与语义组件库）

选定单页版式骨架后，按每块内容的表达意图从组件库中挑选原子组件装配进对应槽位，保证整套 PPT 风格高度统一且信息密度高而不乱。

## 1. Design Tokens（视觉原子变量）

### 配色 Tokens（红灰高对比四色体系，厂商中性）

| Token | Hex | 用途 |
| --- | --- | --- |
| `bg-canvas` | `#FFFFFF` | 画布底色 |
| `accent-red` | `#C00000` | 主标题、章节红带、卡片标题、左强调竖条、流程箭头 `→`、核心量化收益数字、终页金句条 |
| `text-primary` | `#1D1D1A` | 卡片正文、加粗引导词、表格正文 |
| `text-strong` | `#151515` | 底部「洞察启示」正文、终页黑底标题栏 |
| `text-muted` | `#525252` | 页眉副标题、论文出处、图注、表格脚注、页码 |
| `surface-subtle` | `#F2F2F2` | 底部洞察条、顶部论点/串联条、KPI 卡、层级标签栏、表格表头、观察悬念盒 |
| `border-default` | `#D3D3D3` | 页眉细灰线、卡片外框（`0.75-1.0 pt`）、栏间竖线 |
| `border-light` | `#E0E0E0` | 卡片内部子区块分隔横线（`0.01 in`） |
| `text-inverse` | `#FFFFFF` | 红底或黑底上的反白文字 |

配色硬规则：正文红字仅用于结构标签（`问题` / `方案` / `收益`）与每栏 3-5 处核心数字；禁止深色背景、渐变、彩虹标签和残留审稿高亮色块（如 `#FFFF00`）。

### 字体与字号 Tokens（统一 `Microsoft YaHei` / `Microsoft YaHei UI`，纯英文图注可辅 `Arial`）

- `font-divider-title` / `sub`：`23 pt` 加粗 `#FFFFFF` / `16 pt` 常规 `#FFFFFF`
- `font-slide-title`：`17 pt` 加粗 `#C00000`
- `font-slide-sub`：`10 pt` 常规 `#525252`
- `font-kpi-num` / `label`：`16 pt` 加粗 `#C00000` / `9 pt` 常规 `#525252`
- `font-card-title`：`11.2-12.0 pt` 加粗 `#C00000`（三栏窄卡 `10.0-11.5 pt`）
- `font-insight-label` / `body`：`10 pt` 加粗 `#C00000` / `9.8-10.5 pt` 加粗 `#151515`
- `font-body-dense`：`8.2-9.0 pt` `#1D1D1A`（中密度总览页 `9.5-10.0 pt`）
- `font-caption`：`7.5-8.0 pt` 常规 `#525252`
- `font-page-num`：`9 pt` 常规 `#525252`

## 2. 语义组件库（按表达意图选型）

### A. 框架与导航组件

- **页眉组（Header Block）**：红字判断句标题 + 灰字副标题（含正式论文原题/Session/页码）+ `y=1.06` 细灰横线。
- **章节红带（Section Banner）**：居中满宽 `#C00000` 横带，反白居中大标题与单句论点。
- **页码（Page Number）**：右下角 `9 pt` 灰色纯数字。

### B. 观点与强调组件

- **顶部论点 / 串联条（Top Context Strip）**：`(0.50, 1.17, 12.33, 0.40-0.57)`，`#F2F2F2` 底 + 左侧 `0.03 in` `#C00000` 竖条。用于「核心论点」「拟串链路（A → B → C）」「承接上页」或「评测基准」。
- **底部洞察启示条（Bottom Insight Bar）**：`(0.50, 6.49, 12.33, 0.59)`，`#F2F2F2` 底 + 左侧 `0.03 in` `#C00000` 竖条 + 左标「洞察启示」+ 右侧 1-2 行加粗落地结论。
- **栏内佐证微卡（Inline Callout Box）**：浅灰底 `#F2F2F2` 或细灰框 `#D3D3D3`，嵌入卡片底部或侧边，用于高亮消融实验、硬件校准基准或核心能力对比。
- **双态结论盒（Convergence & Watchlist Boxes）**：终页右侧使用——黑顶白字框（`#151515` 顶栏 + 白底黑框）放「已收敛共性规律」，浅灰虚线框（`#F2F2F2` 底 + `#909090` 虚线边）放「开放观察悬念」。

### C. 正文与逻辑陈述组件

- **观点陈述 Bullet（Lead-in Bullet）**：格式为「**加粗 3-8 字引导词** + 冒号/空格 + 凝练陈述（无末尾句号）」，单条不超过 2-3 行，便于快速扫读。
- **机制拆解步骤（Numbered Mechanism ①②③）**：复杂方案强制拆分为 `① ② ③` 编号条目，每步先加粗机制名称再讲因果落地，杜绝笼统概括。
- **KPI 大字指标卡（KPI Metric Tile）**：`#F2F2F2` 底 + `#D3D3D3` 框，上行 `16 pt` 红字加粗核心指标，下行 `9 pt` 灰字口径说明，适合 4 个并排置顶。

### D. 图解与数据组件（图文并茂核心）

- **原文论文图卡（Paper Figure Card）**：300 DPI 精准裁剪去原英文图注、锁定原始纵横比 + 下方紧贴 `7.5-8.0 pt` 灰字中文结论图注（`Fig. X  一句话中文结论`）。
- **轻量原生流程条（Native Pipeline Strip）**：原文缺架构图时，用 3-4 个 `#F2F2F2` 底 `#D3D3D3` 框步骤块 + `→` 箭头横向拼接（如 `① 保缺陷上抬 → ② 统一抽象 → ③ 锁步切差异 → ④ 局部证明`）。
- **极简高密度对比表（Minimal Dense Table）**：浅灰表头 `#F2F2F2`、细灰横线、去掉多余竖线，关键行或最优指标用 `#C00000` 加粗突出。
- **跨栏因果箭头（Flow Connector）**：`16 pt` `#C00000` 箭头 `→`（横向因果流）或红色实心下箭头（纵向分层全景）。

## 3. 组件组合速查（避免选错组件）

- 要交代「上下页或左右栏怎么串起来」→ 用 **顶部串联条**，不要塞进页眉副标题。
- 要讲清「算法/系统具体怎么做」→ 用 **机制拆解步骤 ①②③** + **原文图卡 / 原生流程条**，不要写一整段无编号散文。
- 要突出「一组关键消融或对比数据」→ 用 **极简对比表** 或 **栏内佐证微卡**，不要全堆在普通 bullet 里。
- 要沉淀「对我们团队的启发」→ 统一放 **底部洞察启示条**，不要散落在各栏末尾。
