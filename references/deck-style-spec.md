# 多页技术洞察 PPT 风格规范（红灰高密度工程体系）

本规范面向多页技术洞察报告、顶会论文集综述、架构/编译器/系统方向务虚会报告，覆盖配色、字体、8 类 16:9 版式骨架、工程文案与配图标准。所有视觉参数均保持厂商中性（纯白底 + 炭黑正文 + 浅灰容器 + 主题红点缀）。

## 1. 配色体系（红灰高对比四色系统）

全套 PPT 严格控制在四个视觉角色内，保证高信息密度下在投影与屏幕端均清晰易扫读：

| 视觉角色 | Hex 色值 | 使用场景 |
| --- | --- | --- |
| 画布底色 | `#FFFFFF` | 全套内容页与章节页底色 |
| 主题强调红 | `#C00000` | 主标题、章节过渡页横幅、卡片小标题、左边框强调条（`0.03 in`）、流程箭头（`→`）、核心量化收益数字、终页总结横幅 |
| 正文主色 | `#1D1D1A` | 卡片正文、加粗引导词、表格正文 |
| 强黑强调 | `#151515` | 底部「洞察启示」正文、终页黑底标题条 |
| 次要中灰 | `#525252` | 页眉副标题、论文出处、图注（`Fig. X`）、表格脚注、右下角页码 |
| 容器浅灰 | `#F2F2F2` | 底部「洞察启示」条、顶部导语/论点/串联条、KPI 指标卡、层级标签栏、表格表头、观察悬念框 |
| 边框与分割线 | `#D3D3D3` / `#E0E0E0` | 页眉下方水平细线（`0.01 in`）、卡片外框（`0.75-1.0 pt`）、栏内子区块分隔线 |
| 反白文字 | `#FFFFFF` | 章节过渡页红底白字、终页红底/黑底白字 |

配色克制原则：
- 禁止深色整页背景、彩虹渐变或装饰性多色标签。
- 卡片正文中仅对结构标签（`问题` / `方案` / `收益`）和每栏 3-5 处核心量化数字使用 `#C00000`，避免整句标红破坏视觉层级。
- 最终交付前清除所有审稿/草稿批注色块（如 `#FFFF00` 黄色高亮框）。

## 2. 字体与字号层级（16:9 宽屏：`13.33 × 7.50 in`）

全套中英文统一使用 `Microsoft YaHei` 或 `Microsoft YaHei UI`（纯英文图表标签可辅以 `Arial`）。

| 元素 | 字号 | 字重 | 色值 | 基准位置 / 说明 |
| --- | --- | --- | --- | --- |
| 章节页主标题 | `23 pt` | 加粗 | `#FFFFFF` | 居中于通栏红带内 |
| 章节页副标题 | `16 pt` | 常规 | `#FFFFFF` | 紧随主标题下方，一句核心论点 |
| 内容页主标题 | `17 pt` | 加粗 | `#C00000` | `(0.50, 0.28)`，宽 `12.33 in` |
| 页眉副标题 / 出处 | `10 pt` | 常规 | `#525252` | `(0.50, 0.70)`，宽 `12.33 in` |
| KPI 关键数字 / 说明 | `16 pt` / `9 pt` | 加粗 / 常规 | `#C00000` / `#525252` | 顶部四等分指标卡 |

| 底部「洞察启示」标签 / 正文 | `10 pt` / `9.8-10.5 pt` | 加粗 / 加粗 | `#C00000` / `#151515` | 底部通栏灰底红边条 |

| 页码 | `9 pt` | 常规 | `#525252` | 右下角 `(12.40, 7.15)` |

排版微调细节：
- 中文与英文/数字之间保留半角空格（如 `3D 堆叠`、`1.43×`、`2.82 mm²`）。
- 统一使用标准数学与逻辑符号（`×`、`≤`、`≥`、`→`），不以字母 `x` 或 `<=` 替代。

## 3. 统一网格与 8 类标准页型

### 通用页框安全区
- **画布尺寸**：`13.33 × 7.50 in`（16:9 宽屏），左右边距各 `0.50 in`，有效内容宽 `12.33 in`。
- **页眉区**：`y = 0.28..1.06 in`，以 `y = 1.06 in` 处 `12.33 × 0.01 in` `#D3D3D3` 水平细线收束。
- **主内容区**：常规 `y = 1.21..6.35 in`（高 `5.14 in`）；若顶部增设浅灰红边导语/串联条（`y = 1.17, h = 0.40-0.57 in`），卡片区下移至 `y = 1.67..6.38 in`。
- **底部「洞察启示」条**：`x = 0.50, y = 6.49, w = 12.33, h = 0.59 in`，浅灰底 `#F2F2F2` + 左侧 `0.03 in` `#C00000` 竖条；左区标签 `w = 1.31 in`，右区 1-2 行落地结论。

### 8 类标准页型坐标骨架

1. **趋势词云与导读页**：左 ~68% 放历年演进图或主题词云，右 ~30% 放 4-5 条编号观察（红字编号 + 加粗小标题 + 单行解释）。
2. **三层架构全景页**：上（业务负载层）/ 中（核心发力域，用 `#C00000` 外框与左竖条高亮）/ 下（硬件架构层）三层横向大卡；每层左侧 `1.57 in` 浅灰标签栏，右侧 3-4 列细分主题（`0.01 in` 竖灰线分隔），层间用红色向下箭头连接。
3. **章节过渡页**：纯白底居中通栏红带（`x = 0, y = 3.16, w = 13.33, h = 1.36 in`, `#C00000`），内含居中白色章节大标题（`23 pt`）与一句核心论点（`16 pt`）。
4. **单篇深度页（KPI 横幅 + 三栏）**：顶部 4 等分 `#F2F2F2` KPI 卡片（`3.08 × 0.61 in`），下方 3 等分白底灰框卡片（`4.02 × 4.39 in`，间距 `0.14 in`），配底部洞察条。
5. **单篇深度页（三栏因果流「问题 → 方案 → 收益」）**：三张白底灰框卡从左到右排列，常用非对称宽度 `3.55 in`（问题）/ `4.76 in`（方案，最宽）/ `3.52 in`（收益），栏间居中置 `16 pt` `#C00000` 箭头 `→`，配底部洞察条。
6. **双篇对比 / 串联页（双栏卡片）**：左右两等分白底灰框卡（各 `6.06 × 5.14 in`，中距 `0.21 in`）；栏内纵向按「问题 → 方案（①②③）→ 配图与图注 → 收益」排布，区块间用 `0.01 in` 灰线分隔；可选顶部浅灰红边「核心论点 / 拟串链路 / 评测基准」条。
7. **三篇并列专题页（顶部定义条 + 三等分卡）**：顶部浅灰红边条定义统一问题与 3 个正交维度，下方三等分卡片（宽 `4.02 in`）分别以 `① / ② / ③` 编号，对齐各栏的「问题 / 方案 ①②③ / 配图 / 收益」垂直高度。
8. **终页趋势收束页**：左 ~58% 放「传统共识 → 新现实」对比表（浅灰列 + 红箭头 + 淡红/白底红字新现实列），右 ~40% 上下堆叠黑顶框「跨章节共性规律」与浅灰虚线框「持续观察的行业悬念」，底部通栏 `#C00000` 白字总结金句（`h = 0.50 in`）。

## 4. 工程写作与内容规范

- **判断句主标题 + 正式论文原题核实**：主标题必须是一句完整的技术判断或核心结论，而非「XX 论文解读」；副标题或卡片标题必须核对原文 PDF 并使用**正式论文标题**、会议 Session 与页码，禁止用非正式别名或自造简称代替论文标题。
- **严谨「问题 → 方案 → 收益 → 洞察启示」逻辑链**：
  - **问题**：交代真实负载场景、量化瓶颈与既有方案失效原因，不写空泛背景。
  - **方案**：先用一句话点明核心思路，再拆解为 `① ② ③` 具体落地机制，确保未读过原文的工程师能看懂实现路径。
  - **收益**：明确给出「指标 + 幅度 + 基线 + 条件」，简明扼要，不以孤立相对数字充数。
  - **洞察启示**：不复述论文摘要，站在工程/架构/编译视角给出 1-2 条明确可执行的判断或动作调整。
- **平实通俗的工程表达（禁用比喻）**：用直白、精准的因果与机制语言解释技术原理，减少冷门缩写堆砌；**禁止使用比喻、拟人或文学化修辞**，同时避免宣传口吻与空洞热词。
- **无句号与引导词结构**：所有正文要点、子条目、表格单元格与图注末尾**不加中文句号 `。`**（多句并列用分号 `；` 或逗号 `，` 分隔）；每条采用「**加粗短引导词** + 冒号/空格 + 精准陈述」。
- **事实 100% 溯源**：所有数字、加速比、误差率、硬件参数和论文出处均须回查原文，严禁编造或凭记忆估算。

## 5. 配图与自绘组件规范

- **高信号原文图优先**：优先选取原文的架构/机制流程图与核心定量实验图，避免纯装饰插图、封面图或无信息量示意图。
- **300 DPI 精准裁图去原注**：将源 PDF 页面以 300 DPI 渲染后按精确 bbox 裁剪，**裁掉原文自带英文图注（`Fig. X ...`）** 并去除多余白边。
- **自写中文结论型图注**：每张图下方配一行 `7.5-8.0 pt` `#525252` 自写图注，格式为 `Fig. X  一句话中文结论`（保留原文图号以便溯源）。
- **等比缩放与留白平衡**：严格锁定图片原始宽高比（严禁拉伸变形）；并排多图顶边或底边对齐；若图上方出现大段空洞留白，优先补全方案的 `①②③` 细节并微调图高与垂直间距。
- **轻量原生组件补充**：原文缺少直观流程时，用 `#F2F2F2` 填充 + `#D3D3D3` 边框的步骤块加 `→` 箭头绘制紧凑流程条；多维数据对比优先使用极简原生表格（浅灰表头、细灰横线、关键行/值红字加粗）。

## 6. 交付前视觉自检清单

- 每页导出 PNG 目视检查：无文字溢出、无文本框与图片重叠、栏间密度与留白均衡。
- 图片纵横比完整无变形，图注与图号一一对应且无英文原图注残留。
- 全文检索确认无残留中文句号 `。`（完整段落式章节副标题除外），无未删除的草稿黄色高亮框，且所有论文标题与数据均已核实。
